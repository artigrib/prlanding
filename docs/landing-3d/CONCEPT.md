# printedrobotics.cz — концепт нового лендинга

## Что есть сейчас (факты из репо artigrib/prlanding)
- Статический сайт printedrobotics.cz (CNAME), без сборки: чистый HTML/CSS/JS, three.js 0.186 в vendor/ (GLTFLoader + meshopt). Языки: cs (основной) + /en.
- Разделы: katalog/rejstrik, sim (симуляция SO-101, арена), stavba (7 этапов сборки, 10–19 ч), lab, plan, sada (наборы), pro-skoly (школы), navody, bench (бенчмарк управления ИИ/MCP), kviz.
- Каталог: data/registry/projects.json — 168 open-source робот-проектов, 16 категорий (wheeled 32, legged 20, arm 19, lab-automation 18, actuator 16 …), с лицензиями, BOM-ценой, зрелостью, fit для maker/school/lab, источниками.
- 30 GLB-моделей в models/ (spot, so101, exomy, sawppy, lekiwi, svrn, otto, thor, parol6 …), 16–24 отдельных меша каждая → идеальны для exploded view. Лицензии в models/NOTICE.txt (CC BY/BY-SA и др. — нужна атрибуция).
- Текущий hero — про «попробуйте робота в браузере, потом соберите»; это B2C/мейкер-подача, нет блока для фондов/партнёров (impact, цифры, роадмап).

## Структура нового лендинга
1. **Hero (scroll 3D, pin ~300vh):** робот (Spot или SO-101) вращается → разлетается на детали → подписи деталей (печать / электроника / цена BOM / лицензия) → собирается обратно. Заголовок: «Открытая робототехника: от репозитория к роботу на столе».
2. **Цифры (счётчики):** 168 проектов, 30 3D-моделей, 16 категорий, X школ/уроков, X сборок (*цифры трекшна — уточнить у Марты, в репо их нет*).
3. **Стена проектов:** бесконечный marquee из 2–3 рядов карточек из projects.json (рендеры GLB/фото), фильтр по категориям, клик → каталог.
4. **Как это работает (3 шага):** Сим в браузере → печать и BOM → сборка/образование.
5. **ИИ/MCP + bench:** «рукой в симуляции управляет Claude» — технологическая глубина для грантов.
6. **Образование / школы:** бесплатные уроки на чешском — social impact.
7. **Для партнёров и фондов:** проблема (робототехника дорогая и закрытая) → решение → impact-метрики → роадмап (секция «Na čem pracujeme») → CTA «Скачать one-pager / Связаться».
8. **Открытость и лицензии:** доверие (проверенные источники, rights_class).

## Техника (под текущий стек, без сборки)
- Vanilla three.js из vendor/ + нативный scroll (как в прототипе) либо GSAP ScrollTrigger (один файл в vendor) для pin/scrub.
- Exploded view: для каждого верхнего узла GLB — вектор от центра модели к центру детали (+ лёгкий подъём по Y), смещение = вектор × прогресс × случайная задержка (stagger). Без ручной разметки, работает на любой из 30 моделей.
- Можно менять модель по главам скролла (spot → so101 → exomy) = «много проектов».
- Производительность: модели 40–500 КБ (meshopt) — ок; DPR ≤ 2, рендер только при скролле, lazy-load после первого экрана, prefers-reduced-motion → статичный кадр; на слабых мобилках — заранее отрендеренная sequence/видео или PNG.
- Атрибуция моделей в футере (NOTICE).
